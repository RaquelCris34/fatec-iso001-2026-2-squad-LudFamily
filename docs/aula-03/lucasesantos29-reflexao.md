## 2. Processo

Explique com suas palavras a diferença entre programa e processo: Programa é um conjunto de instruções. Processo é um programa em execução.

## 3. Proteção

Quem negou a leitura do arquivo e por quê? O kernel do sistema operacional negou a leitura porque o arquivo estava sem permissões de acesso (chmod 000).

## 4. Projeto da squad

Escolha UM componente do projeto: Arquivos do projeto (storage).

Esse componente rodaria como quê? Como arquivo no sistema de arquivos.

Se ele falhar, qual impacto de negócio aparece? Perda de acesso às informações e evidências do projeto.

Qual controle deveria existir? Controle de permissões e versionamento pelo Git.
